## app_status

Status of the OrcaSlicer window this server drives: application version, printer and process presets in use, project name and unsaved state, filaments, what is busy right now (slicing, running jobs, an open dialog or gizmo, and whether changes are blocked), the next undo and redo step, the folders files may be read from and written to, and the coordinate and id conventions. Call it first in a session, and again when a call fails with ui_busy.

No arguments.

## history

Undo, redo and the change journal. action "list" (default) returns the names of the undo steps (most recent first), the redo steps, and the journal: changes the undo stack does not cover (preset edits, filament list and colours), newest first. Every change made through this server is one undo step named "MCP: ...", mixed with the user's own steps. action "undo" / "redo" moves `steps` steps (default 1); action "revert" reverts the journal entries in `journal_seq`. Both return a scene summary. Undo also reverts the user's steps if they are on top: check the names first.

| Argument | Type | |
|---|---|---|
| `action` | `list` \| `undo` \| `redo` \| `revert` | default `"list"` |
| `steps` | integer | How many steps to undo or redo.; 1..50, default `1` |
| `journal_seq` | integer[] | For action "revert": seq numbers of journal entries.; at least 1 |
| `if_rev` | integer | Fail with `conflict` unless the scene revision (rev from scene_get or the last result) still has this value. |

## job_status

Progress and result of a long-running operation started by another tool (slice, arrange, orient, mesh operations): status running | finished | failed | cancelled, percent, status text and, when finished, the result. Without `job` it reports the most recent job (optionally of one `kind`). With wait_s > 0 the call waits until the job ends or the time is up, so one call replaces a polling loop.

| Argument | Type | |
|---|---|---|
| `job` | string | a job id such as job3, as returned by the tool that started it |
| `kind` | string | Without `job`: only consider jobs of this kind, e.g. "slice". |
| `wait_s` | number | Wait up to this many seconds for the job to end.; 0..280, default `0` |

## job_cancel

Stop a running long operation (see job_status). Without `job` it stops the most recent running job. The operation stops shortly after; call job_status to see the final state. Work already applied to the scene is not rolled back; use history to undo.

|---|---|---|

## mesh_query

Measure and inspect model geometry without changing it. kind "stats": facets, volume, surface area, whether the mesh is closed (manifold), size and bounding box of objects or parts. "overhangs": the area that faces downward within threshold_deg of straight down (the support painting gizmo's test), with the largest connected regions and their boxes - use it to judge whether and where supports are needed before slicing. "flat_faces": the faces an object could be laid on (planes of its convex hull, largest first) with their normals, for choosing an orientation. "raycast": what a ray hits - give a `pixel` of a screenshot together with that screenshot's `camera`, or an `origin` and `direction` - returning the object, part, facet, point and surface normal; this turns "the thing I see at pixel (520, 300)" into a point on the model. "distance": between two points. Positions and boxes are in plate coordinates (mm).

| Argument | Type | |
|---|---|---|
| `kind` (required) | `stats` \| `overhangs` \| `flat_faces` \| `raycast` \| `distance` |  |
| `targets` | [Id](#shared-types)[] | Object, instance or volume ids. Required except for raycast (default: every object) and distance.; at least 1 |
| `threshold_deg` | number | overhangs: a facet counts when its normal is within this angle of straight down.; 0..90, default `45` |
| `limit` | integer | overhangs: how many regions to list.; 1..100, default `10` |
| `pixel` | [Vec2](#shared-types) | raycast: [u, v] in a screenshot, from its top-left corner. |
| `camera` | object | raycast: the "camera" object of the screenshot the pixel is from, unchanged. |
| `origin` | [Vec3](#shared-types) | raycast: start of the ray, plate coordinates. |
| `direction` | [Vec3](#shared-types) | raycast: direction of the ray. |
| `plate` | [PlateRef](#shared-types) | raycast: the plate whose coordinates origin and the reported ray use (default: current). |
| `a` | [Vec3](#shared-types) |  |
| `b` | [Vec3](#shared-types) |  |

## scene_get

Scene tree of the open project: plates with their objects, instances (position, rotation, scale, bounding box, whether outside the plate), parts and modifiers (type, filament, size, per-part setting overrides), height ranges, paint summary, plus the project, printer, process preset and filaments. Positions are in mm in the frame of the object's plate. detail "summary" gives counts only, "normal" the full tree, "full" adds matrices, per-volume boxes and mesh statistics. Restrict with `plate` or `objects`; large scenes are paged (`truncated`, `next` -> pass as `offset`). The ids returned here are what every other tool takes.

| Argument | Type | |
|---|---|---|
| `detail` | `summary` \| `normal` \| `full` | default `"normal"` |
| `plate` | [PlateRef](#shared-types) |  |
| `objects` | [Id](#shared-types)[] | Only these objects (instance and volume ids select their object). |
| `offset` | integer | >= 0, default `0` |
| `limit` | integer | Maximum number of objects returned.; 1..500, default `50` |

## object_update

Rename an object or part, mark objects or instances printable / not printable, or assign a filament slot to objects, parts or modifiers. `filament` is a 1-based slot from filament_list; 0 on a part or modifier means "use the object's filament". One undo step. Returns the changed objects in scene_get shape. Transforms are object_transform; settings are settings_set.

| Argument | Type | |
|---|---|---|
| `targets` (required) | [Id](#shared-types)[] | Object ids (o...), instance ids (i..., printable only) or volume ids (v..., name and filament only).; at least 1 |
| `name` | string | New name; one target only. |
| `printable` | boolean |  |
| `filament` | integer | 1-based filament slot; 0 on a part or modifier = inherit from the object.; >= 0 |
| `if_rev` | integer | Fail with `conflict` unless the scene revision (rev from scene_get or the last result) still has this value. |

## settings_search

Find print, filament and printer settings by keyword, category or owner. Each hit gives the key to use with settings_get / settings_set, its label, type, unit, range, allowed values, default, which preset type owns it (process, filament, printer, project) and the scopes where it can be overridden (plate, object, part, modifier, layer_range). Query words are matched against the key, label, category and description; all words must match. Without arguments it returns the categories with counts. Labels and descriptions are in English.

| Argument | Type | |
|---|---|---|
| `query` | string | Words to look for, e.g. "infill density", "seam", "wall_loops". |
| `category` | string | Only settings whose category contains this, e.g. "Strength", "Support", "Speed". |
| `owner` | `process` \| `filament` \| `printer` \| `project` |  |
| `scope` | [Scope](#shared-types) | Only settings that can be set at this scope. |
| `mode` | `simple` \| `advanced` \| `expert` | Only settings shown in this user mode or a simpler one. |
| `limit` | integer | 1..100, default `20` |
| `offset` | integer | >= 0, default `0` |

## settings_get

Read setting values at a scope: "process", "printer", "project", {"filament": slot}, {"plate": n}, {"object": id}, {"volume": id} or {"layer_range": {object, z_min, z_max}}. With `keys`, returns those values as stored at the scope (null when the scope does not set the key). With effective: true, returns for each key the value in force for that item and where it comes from (process, plate:1, object:o57, volume:v77 ...): narrower scopes override wider ones. Without `keys`, returns what is modified at the scope: for a preset the keys that differ from the saved preset, for an object, part or range its overrides. Values: numbers, booleans, strings; percentages as "15%"; lists for per-filament or per-extruder options.

| Argument | Type | |
|---|---|---|
| `scope` (required) | [Scope](#shared-types) |  |
| `keys` | string[] | Setting keys, as settings_search returns them. |
| `effective` | boolean | Return {value, source}: the value in force and the scope it comes from.; default `false` |
| `modified_only` | boolean | Of the given keys, return only those modified at the scope.; default `false` |

By default only presets compatible with the current printer are listed. Paged with limit / offset; `query` filters by name.

| Argument | Type | |
|---|---|---|

| `compatible_only` | boolean | default `true` |

| `offset` | integer | >= 0, default `0` |

## filament_list

The project's filament slots: slot number (1-based, the number objects, parts and paint refer to), preset, material type, colour, and where each slot is used: as the filament of objects, of individual parts or modifiers, or in colour painting.

No arguments.

## screenshot

Picture of the scene from any viewpoint, rendered offscreen with a camera of its own: the user's view is not touched and the window does not have to be visible. view "editor" shows the objects of one plate as in the Prepare tab, on a plain bed (10 mm grid, bold lines every 50 mm, X axis red, Y green, Z blue from the plate origin). Camera: a preset (iso, iso_left, iso_back, iso_back_left, top, bottom, front, back, left, right) or azimuth_deg / elevation_deg (azimuth 0 looks from the front, 90 from the right; elevation 90 looks straight down), a target ("plate", "objects", ids, or a point in plate coordinates), zoom (1 fits the target) and perspective or orthographic projection. Returns the image and, as data: the camera actually used (pass it to mesh_query raycast to turn a pixel into a point on the model), for each object its pixel position and pixel box, and the legend (which colour means what). Pixels are (u right, v down) from the top-left corner.

| Argument | Type | |
|---|---|---|
| `view` | `editor` | default `"editor"` |
| `plate` | [PlateRef](#shared-types) |  |
| `camera` | [Camera](#shared-types) | Default: preset iso, target plate, zoom 1, perspective. azimuth_deg / elevation_deg override the preset's angles. |
| `size` | object | Picture size in pixels. Default 1024 x 768. |
| `size.width` | integer | 64..2048 |
| `size.height` | integer | 64..2048 |
| `editor` | object |  |
| `editor.color_by` | `filament` \| `object` \| `type` | filament: as the editor shows it, with colour painting. object: one colour per object. type: parts grey, modifiers and other bodies in their type colour.; default `"filament"` |
| `editor.overlay` | `none` | default `"none"` |
| `editor.show_modifiers` | boolean | Draw modifiers, negative parts, support blockers and enforcers (translucent).; default `true` |
| `editor.show_bed` | boolean | default `true` |
| `editor.only` | [Id](#shared-types)[] | Draw only these objects, instances or volumes. |
| `editor.highlight` | [Id](#shared-types)[] | Draw these in orange. |
| `editor.transparent` | [Id](#shared-types)[] | Draw these translucent, to see what is inside or behind. |
| `format` | `png` \| `jpeg` | A PNG over 900 kB is sent as JPEG instead.; default `"png"` |
